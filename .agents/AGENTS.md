# Reglas del proyecto Fluye

Fluye es una plataforma de crédito empresarial. Este prototipo se corrige para ajustarlo a los estándares documentales.

## Cambios de UI
- Todo cambio debe ser estéticamente cuidado, responsivo y coherente con el design system actual.
- Antes de editar, localiza los tokens, componentes y clases existentes en `index.html` y `app.js`. Reutilízalos y no introduzcas colores, tipografías o espaciados nuevos.
- Usa solo la paleta de colores vigente del prototipo. No metas colores ad hoc.
- Verifica que el resultado se vea bien en móvil, tablet y escritorio. No dejes desbordes ni elementos rotos.
- Si una corrección documental exige un patrón visual que no existe, propónlo al usuario antes de crearlo.
